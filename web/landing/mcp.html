Claude에 Solo Leveling MCP를
연결하는 방법

MCP를 연결하면 원문 근거를 검증한 답변을 받고, 공부한 논문과 메모를 저장해 웹 아카이브에서 다시 볼 수 있어요. 설치 없이 주소 하나만 추가하면 돼요.

바로 연결하기 웹에서 로그인하기

계정 없이 가볍게 써 보고 싶다면 Skill로 먼저 체험해 볼 수도 있어요.

특징

설치 없이 주소 하나로 연결해요

Claude 설정에 주소를 추가하고 로그인하면 끝나요. 논문은 웹에서 올리고, 처리와 저장은 서버가 해요.

연결 방법

단계별로 따라 하기

MCP 서버 주소
https://solo-leveling-staging.soogyung.com/mcp
  1. 1

    웹 아카이브 계정 만들기

    Solo Leveling 웹에 로그인해요. 처음이면 로그인 화면에서 Sign up을 눌러 가입해요. 이메일·비밀번호 또는 Google 계정을 쓸 수 있어요.

    웹에서 로그인하기

    Claude 계정과는 별개의 Solo Leveling 계정이에요. 다음 단계에서도 같은 계정으로 로그인해야 기록이 이어져요.

  2. 2

    Claude에 커넥터 추가하기

    1. Claude에서 설정 → 커넥터(Connectors)로 가요.
    2. 사용자 지정 커넥터 추가(Add custom connector)를 눌러요.
    3. 이름에 Solo Leveling, 주소에 위의 MCP 서버 주소를 붙여 넣고 추가해요.
    4. 목록에서 Solo Leveling의 연결(Connect)을 누르면 로그인 화면이 열려요. 1단계와 같은 계정으로 로그인하고 권한을 허용해요.

    Claude 버전과 요금제에 따라 메뉴 이름이나 위치가 조금 다를 수 있어요.

  3. 3

    웹에서 논문 PDF 올리기

    웹 아카이브의 새 PDF 등록 준비 화면에서 PDF를 올려요. 단계마다 동의를 따로 받아요.

    1. PDF 파일을 고르고, 파일 정보를 서버로 보내는 데 동의해요.
    2. PDF 보관 동의를 저장하고 PDF 업로드를 눌러요.
    3. 업로드 검증이 끝나면 AI 전송 동의를 저장해요. 그러면 서버가 논문을 처리해요.
    새 PDF 등록하러 가기

    PDF는 최대 50MB까지 올릴 수 있어요. 처리에는 몇 분이 걸릴 수 있어요.

  4. 4

    Claude에서 공부하기

    새 대화에서 도구 목록의 Solo Leveling이 켜져 있는지 확인하고 이렇게 말해 보세요.

    • “내 논문 목록 보여줘.”
    • “Attention 논문 학습 시작해 줘. 목적은 이해야.”
    • “왜 √dk로 나누는지 근거와 함께 알려줘.”

    처음 도구를 쓸 때 허용 창이 뜨면 허용을 눌러요.

  5. 5

    웹에서 다시 보기

    공부한 논문, 학습 기록, 메모는 웹 아카이브에서 다시 볼 수 있어요.

문제 해결

도구 목록에 Solo Leveling이 보이지 않아요.

Claude 설정의 커넥터 목록에서 Solo Leveling이 연결됨 상태인지 확인해요. 새 대화의 도구 목록에서 Solo Leveling이 켜져 있는지도 확인해요.

로그인했는데 웹에 기록이 안 보여요.

Claude 커넥터와 웹 아카이브에 같은 계정으로 로그인했는지 확인해요.

내 논문이 목록에 없어요.

웹에서 PDF 업로드와 AI 전송 동의까지 마쳤는지, 서버 처리가 끝났는지 확인해요. 처리 중인 논문은 완료된 뒤에 Claude에서 공부할 수 있어요.

비용이 드나요?

논문 처리와 답변 생성은 서버가 해서 사용자의 OpenAI API 키가 필요 없어요.

설치 없이 먼저 써 보고 싶다면

Skill을 올리면 대화 안에서 바로 논문을 공부할 수 있어요. 서비스 전체 소개는 랜딩 페이지에서 볼 수 있어요.
