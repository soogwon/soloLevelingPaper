설치 방법

단계별로 따라 하기

MCP 서버 주소
https://solo-leveling-staging.soogyung.com/mcp
  1. 1

    웹 아카이브 계정 만들기

    Solo Leveling 웹에 로그인해요. 처음이면 로그인 화면에서 Sign up을 눌러 가입해요. 이메일·비밀번호 또는 Google 계정을 쓸 수 있어요.

    웹에서 로그인하기

    Claude 계정과는 별개의 Solo Leveling 계정이에요. 다음 단계에서도 같은 계정으로 로그인해야 기록이 이어져요.

  2. 2

    Claude에 커넥터 추가하기

    1. Claude에서 설정 → 커넥터(Connectors)로 가요.
    2. 사용자 지정 커넥터 추가(Add custom connector)를 눌러요.
    3. 이름에 Solo Leveling, 주소에 위의 MCP 서버 주소를 붙여 넣고 추가해요.
    4. 목록에서 Solo Leveling의 연결(Connect)을 누르면 로그인 화면이 열려요. 1단계와 같은 계정으로 로그인하고 권한을 허용해요.

    Claude 버전과 요금제에 따라 메뉴 이름이나 위치가 조금 다를 수 있어요.

  3. 3

    웹에서 논문 PDF 올리기

    웹 아카이브의 새 PDF 등록 준비 화면에서 PDF를 올려요. 단계마다 동의를 따로 받아요.

    1. PDF 파일을 고르고, 파일 정보를 서버로 보내는 데 동의해요.
    2. PDF 보관 동의를 저장하고 PDF 업로드를 눌러요.
    3. 업로드 검증이 끝나면 AI 전송 동의를 저장해요. 그러면 서버가 논문을 처리해요.
    새 PDF 등록하러 가기

    PDF는 최대 50MB까지 올릴 수 있어요. 처리에는 몇 분이 걸릴 수 있어요.

  4. 4

    Claude에서 공부하기

    새 대화에서 도구 목록의 Solo Leveling이 켜져 있는지 확인하고 이렇게 말해 보세요.

    • “내 논문 목록 보여줘.”
    • “Attention 논문 학습 시작해 줘. 목적은 이해야.”
    • “왜 √dk로 나누는지 근거와 함께 알려줘.”

    처음 도구를 쓸 때 허용 창이 뜨면 허용을 눌러요.

  5. 5

    웹에서 다시 보기

    공부한 논문, 학습 기록, 메모는 웹 아카이브에서 다시 볼 수 있어요.

    내 기록 보기
내 컴퓨터
  1. 1

    준비물 확인

    • Claude Desktop 앱
    • Python 3.12 (python.org에서 설치)
    • Git: GitHub에서 프로그램을 받을 때 필요해요. macOS는 처음 실행할 때 개발자 도구 설치 창이 뜨면 설치를 누르고, Windows는 git-scm.com에서 설치해요.
    • OpenAI API 키: 논문 번역과 답변 생성에 써요. 사용량만큼 비용이 들어요.
    • 여유 디스크 공간: 검색용 모델과 의존성 때문에 수 GB가 필요할 수 있어요.
  2. 2

    프로그램 설치

    전용 폴더에 파이썬 가상환경을 만들고 Solo Leveling MCP를 설치해요. 터미널(Windows는 PowerShell)에 한 줄씩 붙여 넣어요.

    mkdir -p ~/SoloLevelingPaper
python3.12 -m venv ~/SoloLevelingPaper/venv
~/SoloLevelingPaper/venv/bin/pip install "solo-leveling-paper[local] @ git+https://github.com/soogwon/soloLevelingPaper.git"
    $root = Join-Path $env:LOCALAPPDATA 'SoloLevelingPaper'
py -3.12 -m venv "$root\venv"
& "$root\venv\Scripts\python.exe" -m pip install "solo-leveling-paper[local] @ git+https://github.com/soogwon/soloLevelingPaper.git"

    설치에 몇 분이 걸려요. 마지막에 Successfully installed가 나오면 성공이에요.

  3. 3

    설정 파일 만들기

    설치 폴더에 settings.env 파일을 만들고 아래 내용을 넣어요. 경로는 내 사용자 이름에 맞는 절대 경로로 바꾸고, API 키를 넣어요.

    ~/SoloLevelingPaper/settings.env

    DATA_ROOT=/Users/내사용자이름/SoloLevelingPaper/data
HF_HOME=/Users/내사용자이름/SoloLevelingPaper/models
OPENAI_API_KEY=본인의_API_키
GENERATION_MODEL=gpt-5.4-mini
TRANSLATION_MODEL=gpt-5.4-mini
LOCAL_ONLY=false
ALLOW_EXTERNAL_API=true

    %LOCALAPPDATA%\SoloLevelingPaper\settings.env

    DATA_ROOT=C:/Users/내사용자이름/AppData/Local/SoloLevelingPaper/data
HF_HOME=C:/Users/내사용자이름/AppData/Local/SoloLevelingPaper/models
OPENAI_API_KEY=본인의_API_키
GENERATION_MODEL=gpt-5.4-mini
TRANSLATION_MODEL=gpt-5.4-mini
LOCAL_ONLY=false
ALLOW_EXTERNAL_API=true

    ALLOW_EXTERNAL_API=true로 두면 논문 등록 때 번역을 위해, 질문할 때 답변 생성을 위해 논문 일부가 OpenAI로 전송돼요. 비공개 논문이라면 전송해도 되는지 먼저 확인해 주세요. 이 파일에는 API 키가 들어 있으니 다른 사람과 공유하거나 GitHub에 올리지 마세요.

  4. 4

    점검하고 검색 모델 준비하기

    설정이 맞는지 점검하고, 논문 검색에 쓰는 모델을 미리 내려받아요.

    cd ~/SoloLevelingPaper
venv/bin/python -m solo_leveling.interfaces.cli.desktop check --env-file "$PWD/settings.env"
venv/bin/python -m solo_leveling.interfaces.cli.desktop prepare-model --env-file "$PWD/settings.env"
    $root = Join-Path $env:LOCALAPPDATA 'SoloLevelingPaper'
& "$root\venv\Scripts\python.exe" -m solo_leveling.interfaces.cli.desktop check --env-file "$root\settings.env"
& "$root\venv\Scripts\python.exe" -m solo_leveling.interfaces.cli.desktop prepare-model --env-file "$root\settings.env"

    check가 “점검 완료”를 출력하면 정상이에요. 오류가 나오면 설정 파일의 경로와 값을 다시 확인해요.

  5. 5

    Claude Desktop에 연결하기

    아래 명령이 Claude Desktop 설정에 넣을 내용을 출력해요. 출력된 mcpServers 항목을 Claude Desktop 설정 파일에 합쳐 넣어요.

    cd ~/SoloLevelingPaper
venv/bin/python -m solo_leveling.interfaces.cli.desktop config --env-file "$PWD/settings.env"

    설정 파일: ~/Library/Application Support/Claude/claude_desktop_config.json

    $root = Join-Path $env:LOCALAPPDATA 'SoloLevelingPaper'
& "$root\venv\Scripts\python.exe" -m solo_leveling.interfaces.cli.desktop config --env-file "$root\settings.env"

    설정 파일: %APPDATA%\Claude\claude_desktop_config.json

    Claude Desktop의 설정 → 개발자 → 설정 편집으로도 이 파일을 열 수 있어요. 이미 있는 다른 항목은 지우지 말고 mcpServers 안에 추가만 해요. 저장한 뒤 Claude Desktop을 완전히 종료했다가 다시 열어요.

  6. 6

    논문 등록하고 공부하기

    1. 공부할 PDF를 데이터 폴더의 imports 폴더(DATA_ROOT/imports)에 복사해요.
    2. Claude Desktop 새 대화에서 도구 목록에 solo-leveling-paper가 켜져 있는지 확인해요.
    3. “imports 폴더의 attention.pdf 등록해 줘”라고 말하면 등록 안내 카드가 나와요. 외부 전송 안내를 읽고 동의하면 등록이 시작돼요.
    4. 처리가 끝나면 학습을 시작하고 질문해요.
    • “방금 등록한 논문 처리 상태 알려줘.”
    • “학습 시작해 줘. 목적은 이해, 아는 개념은 RNN이야.”

    처리 중에는 Claude Desktop을 끄지 마세요. 처리가 중단될 수 있어요.

  7. 7

    (선택) 웹 아카이브와 연결하기

    로컬에서 공부한 기록을 웹에서도 보고 싶을 때만 해요. 내 PC를 Solo Leveling 계정에 한 번 연결하면, 이후 Claude 대화에서 동기화 카드로 원하는 논문만 골라 서버에 올릴 수 있어요.

    1. 설정 파일에 서버 주소 SERVER_API_URL=https://solo-leveling-staging.soogyung.com을 추가하고 Claude Desktop을 다시 시작해요.
    2. 계정 연결 명령(solo-leveling-connect --device-name "내 PC")을 실행하면 브라우저에서 로그인 화면이 열려요. 웹 아카이브와 같은 계정으로 로그인해요.
    3. 웹 아카이브의 계정 → 연결된 PC에 내 PC가 보이면 연결된 거예요.

    계정 연결에 필요한 인증 설정 값은 팀에 문의해 주세요. 로그인 정보는 내 컴퓨터의 자격 증명 저장소(macOS 키체인, Windows 자격 증명 관리자)에 안전하게 보관돼요.

문제 해결

도구 목록에 Solo Leveling이 보이지 않아요.

원격은 Claude 설정의 커넥터 목록에서 Solo Leveling이 연결됨 상태인지 확인해요. 로컬은 설정 파일의 mcpServers 항목 경로가 맞는지 확인하고, Claude Desktop을 창만 닫지 말고 완전히 종료했다가 다시 열어요.

로그인했는데 웹에 기록이 안 보여요.

Claude 커넥터(또는 로컬 계정 연결)와 웹 아카이브에 같은 계정으로 로그인했는지 확인해요. 로컬 MCP는 계정을 연결한 뒤 동기화 카드에서 승인한 논문만 웹에 보여요.

원격에서 내 논문이 목록에 없어요.

웹에서 PDF 업로드와 AI 전송 동의까지 마쳤는지, 서버 처리가 끝났는지 확인해요. 처리 중인 논문은 완료된 뒤에 Claude에서 공부할 수 있어요.

로컬 설치에서 check 명령이 실패해요.

설정 파일의 DATA_ROOT, HF_HOME이 절대 경로인지 확인해요. ~나 %LOCALAPPDATA% 같은 줄임 표현은 설정 파일 안에서 풀리지 않아요. 같은 데이터 폴더로 MCP를 여러 개 동시에 실행하지 않아요.

비용이 드나요?

원격 MCP는 서버가 처리해서 사용자의 OpenAI 키가 필요 없어요. 로컬 MCP는 논문 번역과 답변 생성에 본인의 OpenAI API 키를 쓰므로 사용량만큼 비용이 들어요.

설치 없이 먼저 써 보고 싶다면

Skill을 올리면 대화 안에서 바로 논문을 공부할 수 있어요. 서비스 전체 소개는 랜딩 페이지에서 볼 수 있어요.
