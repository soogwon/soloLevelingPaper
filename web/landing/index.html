서비스 소개

읽고, 묻고, 확인하고, 다시 보기

Solo Leveling은 Claude 안에서 논문을 공부하는 흐름 전체를 돕는 도구예요.

근거 있는 한국어 답변

답변마다 원문 문장과 페이지를 함께 보여줘요. 근거에 없는 내용은 근거처럼 말하지 않아요.

목적에 맞춘 학습 순서

이해, 구현, 훑어보기 중 목적을 고르면 먼저 알아야 할 개념과 순서를 개념 지도로 알려줘요.

읽기 전 질문과 퀴즈

읽기 전에 생각해 볼 질문을 받고, 다 읽은 뒤에는 퀴즈로 얼마나 이해했는지 확인해요.

웹 아카이브에 기록 보관

공부한 논문, 메모와 하이라이트, 읽던 위치를 웹에서 다시 보고 컬렉션으로 정리해요.

Skill

Claude에 Skill을 올려 두면 그 대화 안에서 논문을 공부할 수 있어요. 학습 안내, 퀴즈, HTML 교재 Skill 3개가 있어요.

  • solo-leveling-guide 목적별 읽는 순서, 요약, 원문 근거가 붙은 질의응답
  • solo-leveling-quiz 퀴즈 문제지·정답지를 PDF로 만들기
  • solo-leveling-textbook 대화 내용을 HTML 교재로 정리
  1. Claude 설정에서 코드 실행 기능을 켜요.
  2. Skill 폴더를 zip으로 묶어 Claude의 Skills 메뉴에 업로드해요.
  3. 새 대화에서 PDF를 올리고 “이 논문 공부하고 싶어”라고 말해요.

MCP

내 PC에 MCP 서버를 설치해 Claude Desktop과 연결해요. 근거를 검증한 답변을 받고, 기록을 서버에 저장해 웹에서 다시 봐요.

  1. 설치 가이드를 따라 MCP 서버를 설치해요.
  2. Claude Desktop 설정에 MCP를 등록하고 다시 시작해요.
  3. 계정을 연결하면 공부한 기록이 웹 아카이브에 쌓여요.

자주 묻는 질문

Skill로 시작했다가 나중에 MCP로 옮길 수 있나요?

네. 다만 Skill은 기록을 저장하지 않아서, Skill로 공부한 내용은 웹 아카이브로 옮겨지지 않아요. MCP를 설치한 뒤 공부한 기록부터 저장돼요.

서버에는 어떤 기록이 올라가나요?

동의한 논문의 정보, 학습 위치와 읽기 상태, 저장된 요약, 메모와 하이라이트가 올라가요. PDF 원본은 논문마다 따로 동의해야 올라가요. 추출한 원문 전체, 검색용 데이터, 내 PC의 파일 경로, API 키는 올라가지 않아요.

사용하려면 무엇이 필요한가요?

Skill은 Claude 설정에서 코드 실행 기능을 켜고 Skill을 업로드할 수 있어야 해요. MCP는 Claude Desktop과 설치 가이드의 준비물(Python 등)이 필요해요.

Solo Leveling. 학습은 Claude에서, 기록은 여기서 다시 봐요.
