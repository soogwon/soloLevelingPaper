# 논문 학습 방법 안내 (Solo Leveling Paper)

사용자가 올린 논문 PDF 하나로, 대화 안에서 논문을 읽는 방법을 안내하고 함께 공부한다.
답변은 한국어로 하고, 논문 용어는 처음 나올 때 영어 원어를 괄호로 함께 쓴다.

이 Skill은 대화가 끝나면 기록을 남기지 않는다. 사용자가 기록 저장·이어 하기·외부 웹 보기를 원하면
Solo Leveling Paper MCP를 안내한다. 퀴즈 파일은 `solo-leveling-quiz`, HTML 교재는 `solo-leveling-textbook` Skill이 맡는다.

## 1. 시작: 목적과 수준 묻기

PDF가 없으면 먼저 논문 PDF를 올려 달라고 한다. 있으면 한 메시지로 다음을 묻는다.

- 읽는 목적: **이해** / **구현** / **훑어보기**
- 이미 알고 있는 개념 (없으면 "없음")
- (선택) 이 분야 논문을 읽어 본 경험

사용자가 이미 말했다면 다시 묻지 않는다. 목적과 아는 개념을 추측해서 정하지 않는다.
대답이 없으면 기본값 "이해", 아는 개념 없음으로 진행하고 그렇게 했다고 알린다.

## 2. 논문 준비 (스크립트)

```bash
python scripts/pdf_text.py "<업로드된 PDF 경로>" --out paper_text_<짧은 논문 이름>
python scripts/concept_path.py --paper-json paper_text_<짧은 논문 이름>/paper.json --goal <understand|implement|skim> --known "<아는 개념, 쉼표 구분>"
```

- `pdf_text.py`는 페이지별 본문을 `<결과 폴더>/page_NNN.txt`로 저장하고 절 제목 후보를 알려 준다.
- 결과 폴더는 논문마다 따로 쓴다(예: `paper_text_bert`). 같은 폴더가 이미 있으면 스크립트가 덮어쓰지 않고 멈춘다. 그 폴더의 `paper.json` sha256이 지금 PDF와 같으면 다시 풀지 말고 그대로 쓰고, 다른 논문이면 새 이름을 쓴다.
- 종료 코드 2(PDF를 열 수 없음)면 손상·암호·PDF 아님이다. 사용자에게 그대로 알리고 다른 파일을 요청한다.
- 가운데 여백과 양쪽 본문이 확인된 2단 페이지는 왼쪽 단 → 오른쪽 단 순서로 푼다. 혼합 배치·좁은 여백이나 pypdf 대안 추출에서는 읽기 순서를 보장하지 않으므로 인용 전 원문을 확인한다.
  본문 전체를 한꺼번에 읽지 말고, 필요한 페이지 파일만 읽는다.
- 글자가 거의 없는 쪽이 많다고 나오면 스캔본일 수 있다. 사용자에게 알리고 읽을 수 있는 범위에서만 진행한다.
- `concept_path.py` 결과의 `graph_status`:
  - `ready`: 검수된 판본. 학습 순서와 쪽 위치를 그대로 보여 준다.
  - `related_version`: 같은 논문의 다른 판본. 학습 순서는 보여 주되 쪽 위치는 직접 찾아야 한다고 알린다.
  - `no_graph`: 검수된 개념 지도가 없는 논문. 학습 순서를 지어내지 말고 3단계의 일반 전략만 쓴다.

## 3. 읽는 순서 안내

`references/reading-strategies.md`의 4단계(미리보기 → 구조 파악 → 정독 → 복습)를 목적에 맞게 줄이거나 늘린다.
절 제목 후보와 쪽 번호를 이용해 "이 논문에서는 몇 쪽의 어느 절"인지 구체적으로 알려 준다.

개념 지도가 있으면(`ready`·`related_version`) 단계 안내 앞에 학습 순서를 표로 보여 준다.

| 순서 | 개념 | 왜 필요한가 | 논문 위치 |
|---|---|---|---|
| 1 | 내적 (Dot product) | → 행렬 곱에 필요: 행렬 곱의 각 원소가 행과 열의 내적이다. | p.3 · 3.2 Attention |

- `role=required`의 `reason_ko`는 `needed_for` 개념과의 관계 설명이다. "→ {needed_for}에 필요"를 앞에 붙인다.
- `paper_locations`가 비어 있으면 이 결과에 논문 위치가 연결되지 않은 개념이다. 논문에서 다루지 않는다고 단정하지 않는다.
  논문 위치 칸에 "논문 위치 미확인(배경지식으로 보충)"이라고 쓰고, 쪽 번호를 지어내지 않는다.
- `skipped`(아는 개념이라 건너뜀)는 따로 한 줄로 알려 주되, 이해했다는 증거로 취급하지 않는다.
- `unresolved_concepts`는 지도에 없는 이름이다. 그대로 알려 주고 비슷한 이름을 추측해 바꾸지 않는다.
- 특정 개념의 선수 개념을 물으면 `--concept "<이름>"`으로 조회한다. 지도에 없으면 일반 설명은 해도 되지만
  "검수된 선수 관계"라고 말하지 않는다.

## 4. 읽기 전 질문

미리보기 전에 `templates/reading-questions.md`의 읽기 전 질문 3개를 그대로 보여 준다.
답은 선택이다. 사용자가 답하면 기억해 두었다가 복습 단계에서 읽은 후 질문과 나란히 비교한다.
사용자 대신 답을 쓰거나 기존 답을 고치지 않는다.

## 5. 단계별 진행

한 번에 한 단계씩 진행하고, 단계마다 다음을 한다.

1. 읽을 곳(절·쪽)과 이 단계의 목표를 알려 준다.
2. 그 범위의 핵심 내용을 쉬운 말로 설명한다. 근거 규칙은 `references/answer-rules.md`를 따른다.
3. 그 범위에서 처음 나온 키워드를 설명한다(키워드 뽑기 규칙은 `reading-strategies.md`).
4. 이해 확인 질문을 하나 던지고, 다음 단계로 갈지 묻는다.

사용자가 중간에 질문하면 언제든 답하고, 답한 뒤 원래 단계로 돌아온다.

## 6. 질의응답

- 답 → 근거 순서로 쓴다. 근거는 `(p.N, 절)`과 원문 짧은 인용이다.
- 추출한 본문에서 찾지 못하면 그렇다고 말하고, 그림·표·수식에 있을 수 있는 쪽을 안내한다.
- 사용자의 목적에 맞게 깊이를 조절한다(구현이면 입력·출력 모양, 수식, 설정값까지).

## 7. 요약

요약을 원하거나 복습 단계에 이르면 `templates/summary.md` 형식으로 쓴다.
훑어보기 목적이면 템플릿 끝의 짧은 형식을 쓴다. 한계는 논문이 명시한 것만 쓴다.

## 8. 마무리

복습 단계에서 읽은 후 질문 4개를 보여 주고, 읽기 전 답이 있으면 전후 비교표로 나란히 보여 준다.
마지막에 오늘 공부를 어떻게 정리할지 고르게 한다. 선택 질문 도구가 있으면 그것으로, 없으면 번호 목록으로 묻는다.

1. 퀴즈로 확인하기 — 브라우저에서 풀고 바로 채점되는 HTML 퀴즈 → `solo-leveling-quiz` Skill
2. HTML 교재로 정리하기 — 오늘 공부한 내용을 다시 읽을 수 있는 교재 → `solo-leveling-textbook` Skill
3. 둘 다 — 교재를 먼저 만들고, 같은 범위로 퀴즈를 만든다
4. 이번엔 넘어가기

고른 Skill의 순서를 그대로 따른다. 이미 풀어 둔 `<결과 폴더>`와 대화에서 공부한 범위를 그대로 넘겨,
같은 질문을 다시 하지 않는다. 기록을 남기고 다음에 이어 하고 싶다면 Solo Leveling Paper MCP를 안내한다.

## 반드시 지킬 것

- 논문에 없는 내용을 논문의 주장으로 말하지 않는다.
- 쪽 번호와 인용문은 실제로 읽은 페이지 파일에서만 가져온다.
- 검수된 개념 지도가 없는 논문에 "검수된 학습 순서"를 만들어 내지 않는다.
- 사용자가 올린 PDF 원문 전체를 대화에 그대로 옮겨 적지 않는다.
