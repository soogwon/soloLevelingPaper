# 02. 서비스와 페르소나

상태: 기획 초안 / 2026-09-05

## 서비스 정의

AI 챗봇에서 논문을 선택하고 질문하면 원문 근거, 한국어 설명, 목적별 읽기 가이드와 선수 개념을 제공하는 논문 학습 어시스턴트다. M1은 단일 논문 이해, M2는 학습 지속과 논문 간 탐색에 집중한다.

## 페르소나

| 항목 | 메인: 논문 입문자 | 보조: 프로젝트형 개발자 |
|---|---|---|
| 목적 | 수업·개인 학습·취업 준비 | 프로젝트 적용 |
| 지식 | 선수 개념과 수식에 공백 | 개발 경험은 있으나 논문 해석에 공백 |
| 행동 | PDF·문단을 넣고 쉬운 설명 요청 | 방법론·수식 설명과 자료 탐색 |
| 어려움 | 용어 때문에 읽기 중단 | 모델 구조와 자료 탐색 때문에 지연 |
| M1 가치 | 필요한 개념과 읽기 순서 | 목적별 요약과 근거 있는 Q&A |
| M2 가치 | 퀴즈·진도·재개 | 방법론 분석·메모·논문 비교 |

앞선 설문 5건에 기반한 가설형 페르소나다. 시장 전체를 대표하지 않는다. 가상의 이름·연령·성별·MBTI는 추천이나 숙련도 판단에 사용하지 않는다.

## 경험 원칙

처음에는 읽는 목적 정도만 묻는다. 질문에 목적이 들어 있으면 재질문하지 않는다. 진단·퀴즈·선수 단계는 필수 관문이 아니다. 추가 자료는 필요할 때 펼쳐 본다.

입문자는 논문 URL과 이해 목적을 입력하고 요약을 본 뒤 모르는 개념을 질문한다. 원하면 선수 개념과 관련 섹션을 확인한다. 개발자는 입력·처리·출력에 관해 질문하고 방법론 섹션의 근거를 확인한다. 코드 자동 생성은 M1에 포함하지 않는다.

## 검증할 가치

같은 PDF를 제공한 일반 LLM 기준선 대비 근거 확인 시간, 추가 질문 수, 목표 섹션 이해도가 개선되는지 검증한다. 프로토콜이나 그래프 기술 자체를 사용자 가치로 간주하지 않는다. [평가 방법](14-evaluation-and-tests.md)을 따른다.
