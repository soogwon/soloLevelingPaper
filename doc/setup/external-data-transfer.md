# 외부 전송 데이터와 실행 시점 (#64)

현재 로컬 구현의 안내다. 외부 전송이 허용되는 자료인지 확인한 후 API 호출을 활성화한다.
비공개 논문이나 개인정보가 들어 있는 질문·본문은 전송 전에 사용자가 확인해야 한다.
본문의 개인정보를 자동으로 익명화하는 기능은 없다.

## 서버가 OpenAI로 보내는 데이터

현재 번역·생성·의미 검증 어댑터의 목적지는 `https://api.openai.com/v1/responses`다.
API 키는 인증 헤더에 전달된다. 각 요청에는 모델명·지시문·응답 형식·출력 토큰 제한도 포함된다.

| 작업 | 전송 시점 | 전송 내용 |
|---|---|---|
| 번역 | 논문 등록 후 백그라운드 번역 단계 | 청크 원문(`original_text`), 대상 언어 |
| 질문 답변 | 질문의 검색 근거를 확보한 뒤 생성 단계 | 질문, 근거 ID, 한국어 번역과 원문, 문장 경계·인접 근거 정보 |
| 답변 보완 | 미완결 주장 등의 보완이 필요한 경우 | 질문·근거에 더해 보완 대상 초안과 보완 사유·대상 정보, 같은 후보 원문에서 만든 구절 선택지(ID·근거 ID·페이지·위치·원문). 앞·뒤 연결 구절은 함께 선택할 항목으로 제공하며 후보 범위를 확장하지 않음 |
| 의미 검증 (#36, 선택적) | 추출 검사 후 최종 초안이 남았을 때 최대 1회 | 주장 문구·주장 ID·인용 근거 ID, 실제 인용 원문·PDF 페이지·문장 경계·인접 관계. semantic-v4부터 질문 항목 검사를 위해 검색에 사용한 질문, 내용 보존 검사를 위해 보완 전 주장과 결과 ID 대응도 전송. semantic-v6는 같은 최종 주장에서 추출한 답변 구절 목록(ID·주장 ID·위치·구절)도 전송. 번역문·파일 경로·context ID는 별도 필드로 보내지 않음. 질문·주장·원문에 포함된 사용자 정보는 전송될 수 있음 |
| 요약 생성 | 요약 생성기를 사용하는 서비스가 호출할 때 | 근거 ID, 한국어 번역과 원문, 문장 경계 정보. 현재 MCP 도구 연결 여부와는 별개다. |

semantic-v7은 같은 인용 원문에서 만든 구절 목록(ID·근거 ID·페이지·시작/끝 위치·정확한 원문)도 전송한다.
목록은 내부 검증용이며 DB·진단 로그·MCP 응답에는 추가하지 않는다.

PDF 파일 자체·전체 DB·로컬 파일 경로를 위 요청의 별도 필드로 업로드하지 않는다.
다만 등록 시 여러 청크를 번역하므로 누적 전송 범위가 논문 전체 원문에 이를 수 있다.
사용자가 질문이나 본문에 경로·개인정보를 넣었다면 그 텍스트에는 그대로 포함될 수 있다.

번역은 정책에 따라 재시도할 수 있다. 질문은 추가 검색 후 재생성하거나 초안을 보완할 수
있으므로, 도구 호출 한 번이 외부 API 호출 한 번을 뜻하지 않는다. 추가 전송과 비용이
발생할 수 있다. 상태·목록·저장된 근거 조회 자체는 위 생성·번역 API를 호출하지 않는다.

코드는 `store=False`를 요청에 설정하지만, 이는 외부 전송을 막거나 제공자 측 모든
데이터 보관이 없음을 보장하는 의미가 아니다. 제공자 계정의 데이터 처리 조건은 별도 확인한다.

## 호출 허용 설정

| ALLOW_EXTERNAL_API | LOCAL_ONLY | 위 OpenAI 번역·생성·검증 호출 |
|---|---|---|
| false | false 또는 true | 차단 |
| true | true | 차단 |
| true | false | 허용 |

차단 시 로컬 번역·생성 모델로 자동 대체하지 않는다. 번역·생성이 필요한 작업은
실패하거나 사용 불가로 처리될 수 있다. 설정 검증에는 API 키의 존재도 요구하므로,
호출 차단과 키 없는 서버 실행 지원은 같은 의미가 아니다.

설정 파일보다 프로세스 환경변수가 우선한다. 설정을 바꾼 뒤에는 진행 중인 작업을 확인하고
MCP 서버 연결을 재시작해 반영한다. 이미 전송된 데이터는 설정 변경으로 회수되지 않는다.

## 로컬 전용 설정이 차단하지 않는 통신

- MCP 서버는 stdio로 결과를 호스트에 전달한다. 답변·원문 인용·번역·논문 메타데이터 등은
  도구 응답에 포함될 수 있다. Claude 같은 호스트가 이를 어떻게 처리하는지는 호스트의
  설정·정책에 따른다. `LOCAL_ONLY`는 호스트의 통신을 통제하지 않는다.
- 임베딩 계산은 현재 로컬 모델을 사용하지만 캐시가 없으면 모델 파일 다운로드가 필요할
  수 있다. `LOCAL_ONLY`는 모델 라이브러리의 네트워크 차단 설정이 아니다.
- 패키지 설치나 별도 URL 다운로드 기능도 이 두 설정으로 일괄 차단되는 것은 아니다.

따라서 이 설정만으로 완전한 오프라인 실행을 보장하지 않는다.

## 구현·검증 기준

- 번역: `infrastructure/translation/openai_provider.py`
- 답변·보완·요약: `infrastructure/generation/openai_generator.py`
- 의미 검증: `infrastructure/generation/semantic_verifier.py` (추가로 `SEMANTIC_VERIFICATION_ENABLED=true` 필요)
- 환경 설정 우선순위: `interfaces/mcp/runtime.py`
- 실제 API 없이 HTTP 요청을 대역으로 바꿔 차단 여부를 검증한다. 이는 실제 제공자의
  데이터 보관 정책이나 Claude 호스트의 네트워크 동작을 검증하는 테스트는 아니다.
