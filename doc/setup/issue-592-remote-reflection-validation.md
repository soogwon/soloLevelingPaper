# #592 원격 성찰 저장 기반 검증

기존 검수 질문 7개와 비교 묶음을 재사용한다. 첫 저장 시 질문 문구·질문 ID·
묶음·owner/context/판본/publication을 고정한다. 배포 후 템플릿이 변경돼도
저장된 맥락의 질문을 새 문구로 바꾸지 않는다. 읽기만 하면 저장하지 않는다.

- A: 동일 키·동시 저장 1건, 다른 본문의 키 재사용 거부, expected revision
  충돌 검사, 타 계정·삭제 논문 차단, 요청별 결과 재생을 제공한다.
- B: 전후 비교는 현재 저장 답변을 나란히 보여주며 없는 답변은 null이다.
  이해 향상·정답 판정·AI 생성은 하지 않는다. 고정 질문도 논문별 생성 질문은 아니다.
- C: 제품 연결용 질문/답변/비교/삭제/내보내기 저장소 계약을 준비했다.
  실제 MCP·웹 카드·동의 화면·운영 설정은 아직 연결하지 않았다.

## 동의·보존

`remote-reflection-v1` 고지와 고정 맥락/질문 판본 해시의 storage 동의만
작성·수정에 허용한다. 메모·질문·AI 동의를 재사용하지 않는다. 검토용 API나
제품 동의 화면을 연결하기 전에는 운영 저장 기능을 활성화하지 않는다.
철회 후 새 저장은 막지만 기존 조회·내보내기·삭제와 같은 키 재생은 유지한다.

요청 이력은 응답 유실 복구와 내보내기를 위해 보존한다. 답변 삭제 시 현재
본문과 해당 질문의 모든 요청 이력 본문을 지우고 키 tombstone만 남긴다.
과거 키를 재전송해도 삭제 결과만 반환한다. 삭제 후 재작성에도 revision을
계속 증가시켜 오래된 수정·삭제가 새 답변에 적용되지 않게 한다.
맥락 물리 삭제 시 세 테이블은 FK cascade로 제거된다. 전체 계정 내보내기·
학습 기록 삭제 제품 경로의 연결 검증은 후속 범위다.

격리 PostgreSQL 성찰 회귀 8개 통과. migration·백업/복구 포함 36개 확인 후
삭제/재작성 revision 회귀를 다시 통과했다. Ruff·diff 통과.
실제 staging 변경·외부 전송·AI 호출은 없으며 실제 다기기 검증은 남는다.
