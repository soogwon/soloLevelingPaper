# #581 저장 요약의 근거 재조회

저장 요약이 실제 인용한 evidence ID만 해당 요청 키의 고정 입력에서 읽는다.
새 검색·생성·외부 전송 없이 원문·번역·PDF 페이지와 게시/파싱/번역 판본을
반환한다. 미인용 근거·다른 owner·삭제 논문은 반환하지 않는다.

조회 transaction에서 논문 공유 잠금을 유지해 상세 입력을 읽는 사이 삭제와
섞이지 않게 한다. 완료 결과 JSON은 해시뿐 아니라 중복 필드도 거부한다.
최신 성공 조회는 completed만 선택하므로 실패한 재생성이 성공 결과를
덮어쓰지 않는다. MCP에 근거 조회와 최신 성공 조회 도구를 추가했다.

요약 접수/실행/도구 36개 통과 후 중복 JSON 회귀를 추가하여 접수/결과
22개를 다시 확인했다. Ruff·diff 통과. 실제 API·staging 변경 없음.

논문 상세 카드는 현재 summary=null 계약이므로 이 PR에서 바꾸지 않는다.
그 카드·웹 논문 상세·계정 내보내기 연결, 전용 권한/운영 조립과 실제 호스트
검증은 남는다. 현재는 요약 전용 도구를 통해 조회한다.
