# 저장 요약 상세 카드·Markdown 내보내기

Refs #581. staging 변경·PDF 전송·API 호출 없이 구현했다.

- `show_remote_paper_detail` 카드가 기존 `get_latest_remote_summary`를 호출해 같은 맥락의 최신 성공 요약을 별도 조회한다. 요약 조회는 기존 `summaries:write` 권한을 요구하며 논문·메모 조회 권한을 요약 권한으로 확대하지 않는다.
- 범위(전체/섹션), 판본, 생성 시각, 요약 항목과 근거 ID를 표시한다. 기존 상세 응답의 `summary:null`은 호환성을 위해 유지하며 카드가 별도 결과를 표시한다. `get_remote_paper_detail`의 응답 자체를 요약 전문으로 확대하지 않는다.
- 카드의 Markdown 내보내기는 표시 중인 요청 키로 `export_remote_summary`를 호출한다. 소유권·삭제·완료·고정 결과 검증을 기존 `result` 조회에서 적용한 뒤 판본/파싱·번역 리비전/범위/모델/프롬프트/근거 ID를 함께 내보낸다. 새 검색·요약·재접수는 없다.
- Markdown은 읽기 전용 입력란에서 복사해 .md 파일로 저장할 수 있다. 호스트별 다운로드·클립보드 API 지원을 전제로 하지 않는다. 도구를 채팅에서 직접 호출해 같은 Markdown을 받을 수도 있다.
- 요약 없음·권한 없음·오류를 구분하고 새 입력·취소·페이지 종료·다른 맥락/판본 응답은 이전 요약과 내보내기 내용을 지운다. 본문은 textContent/value로 표시하며 내보내기의 HTML·Markdown 링크 구문을 이스케이프한다.

필수 회귀: Python 도구/격리 DB 9개, 카드 11개 통과(총 20). 카드 번들 생성과 Ruff·diff 검사도 통과했다. 성공 요약 재조회/내보내기에서 새 provider 시도가 늘지 않음, 타인·삭제 접근 차단, 늦은 응답 및 XSS 표시 방지를 확인했다.

남은 범위: 실제 최소 DB 권한·운영 설정/배포, 실제 요약 생성 및 품질 실측, Desktop·다기기·두 계정 실기기 검증. 웹 논문 상세와 로컬 동기화 요약을 합치는 변경은 포함하지 않았다. 구조·근거 ID 소속 검증을 의미적 정확성으로 주장하지 않으며 #581은 열어둔다.
