# #400 원격 MCP 운영 준비 체크리스트 — C 초안

상태: 미실행. 이 문서는 설정 변경·배포·운영 공개의 승인이 아니다.
#388 합성 연결 결과와 #399 제품 준비를 구분하고, 실제 설정 작업은 승인된 스테이징에서 수행한다.
수치·담당자·결과가 비어 있으면 통과로 판단하지 않는다.

## 실행 전에 확정할 것

| 항목 | 결정 주체 | 확정값/증거 |
|---|---|---|
| 테스트 대상 commit/image digest, 공개 URL | A/C | |
| API/worker 분리·사양·프록시 제한 | A/Soo | |
| 테스트 계정/최소 scope/client 등록 방식 | A/C, #388 | |
| 사용자·서비스 rate limit 및 유료 한도 | A/B/Soo, #396 | |
| 운영 책임자·연락 경로·중단/복구 결정자 | Soo | |
| 로그 보관/삭제, 백업 만료·복구 범위 | A/Soo, #394/#368 | |
| health/SLO·장애 임계값/알림 대상 | A/B/Soo | |

실제 토큰·secret·계정 식별정보는 표에 넣지 않는다. 비밀 보관소의 관리 절차/담당만 기록한다.
API와 worker 상태를 각각 측정한다. 임베딩 준비 지연을 API health와 같은 성공 신호로 합치지 않는다.

## 중지 제어를 분리한다

| 제어 | 새 유료 작업 | 기존 worker의 다음 제공자 전송 | 저장 결과 조회 | 안내 |
|---|---|---|---|---|
| 신규 유료 접수 차단(구현 필요) | 거부 | 이 제어만으로 차단되지 않음 | 권한 있는 조회 유지 | 새 작업 접수가 중단됐으며 기존 처리는 계속될 수 있음 |
| 추가 제공자 전송 차단(구현 필요) | 별도 접수 정책 적용 | 생성·보완·검증·번역 재시도를 전송 직전 gate에서 거부 | 권한 있는 조회 유지 | 추가 전송 중단. 이미 전송된 요청은 처리/정산 중일 수 있음 |
| 전체 MCP feature flag off | MCP 접수 불가 | worker 중단을 보장하지 않음 | MCP 조회도 불가 | MCP 연결 중단 및 실제 대체 경로 안내 |
| 사용자 접근 폐기/삭제 | 거부 | 확정 정책에 따라 전송 직전 재검사 | 해당 권한 정책대로 거부 | 다른 계정 자료 존재 여부 비노출 |

전체 flag off가 조회 유지 요구를 충족한다고 기록하지 않는다. 현재 flag는 스파이크용이며
제품 유료 접수 차단 제어는 아직 없다. 웹 대체 경로도 구현/검증 전 지원한다고 안내하지 않는다.
이미 전송한 AI 요청을 중지했다고 비용 0/환급을 확정하지 않는다.

## 스테이징 실행 순서

| ID | 실행 | 기대 결과 | 실제 결과/증거 |
|---|---|---|---|
| OPS-01 | 공개 URL·metadata resource·허용 Host·프록시 전달 가정을 대조 | 정확한 URL 일치, 위조 Host 거부 | |
| OPS-02 | 승인된 테스트 자격을 회전하고 새/이전 자격의 허용 정책 검증 | 새 자격 정상, 이전 자격은 정한 폐기 정책대로 거부 | |
| OPS-03 | 합성 요청으로 사용자 한도·서비스 한도 각각 초과 | 정한 제한 응답, 다른 사용자 격리, 자동 유료 재시도 없음 | |
| OPS-04 | 테스트 장애를 주입하고 API/worker 알림 확인 | 담당자에게 안전한 알림, 본문/자격 비노출 | |
| OPS-05A | 신규 접수만 차단, 기존 실행을 다음 단계로 진행시키고 동일 키 조회 | 신규 job/예약 0, 기존 실행은 별도 gate 정책 적용, 저장 조회 유지 | |
| OPS-05B | 추가 전송 차단 후 기존 worker의 생성·보완·검증·번역 재시도 실행 | 차단 판정 이후 새 provider attempt 전송 0, 기존 결과 조회 유지 | |
| OPS-05C | 이미 전송한 요청의 늦은 usage 도착 후 정산 | 한 번만 정산, unknown 보류 자동 환급 없음, 게시 권한 부활 없음 | |
| OPS-05D | 차단 해제 후 같은 실행을 정책대로 복구 | 새 요청 키/총예산 초기화 없음, 기존 소비·보류 유지 | |
| OPS-06 | 정상/오류/재연결/업로드·동의 흐름의 서버·프록시·worker 로그 조사 | 토큰·질문·본문·presigned URL 없음 | |
| OPS-07 | 격리 DB/R2에 공개 fixture 백업을 복원, tombstone 재적용 | 과거 근거 보존, 삭제 자료 재노출 없음 | |
| OPS-08 | 승인된 범위에서 전체 MCP flag off/on 및 기존 API 회귀 | /mcp 폐쇄/재개, 기존 인증/동기화 영향 확인 | |
| OPS-09 | 이전 검증 이미지로 롤백, 재접속 후 같은 job 조회 | 새 중복 실행/예약 없음, 마이그레이션 호환 확인 | |
| OPS-10 | 초대 테스트 사용자만 단계 공개하고 되돌림 | 범위 밖 접근 차단, 같은 실행/동의 상태 보존 | |

회전 검증은 설정 이름 변경만으로 완료하지 않는다. refresh 폐기와 기존 access token 만료 정책을 구분한다.
로그 점검은 합성 식별 표식을 사용하고 원본 로그를 PR/티켓에 붙이지 않는다. 검출 건수와 고정 사유만 보고한다.
전송량/비용/사용량 불명은 원장 수치로 확인하며 UI 상태만으로 중복 과금 0을 판정하지 않는다.

## 중단과 복구

교차 사용자 노출, 동의 없는 유료 전송, 중복 예약, 삭제 자료 재생성, 비밀 로그 유출 발견 시 단계 공개를
중단하고 책임자에게 알린다. 승인된 절차로 접수를 차단하고 필요한 증거를 제한된 장소에 보존한다.
확인 없이 DB를 되돌리거나 tombstone/예산 원장을 삭제하지 않는다.
복구 전 재발 방지 회귀·마이그레이션 호환·현재 승인/예약 상태를 확인하고 결정자가 재개를 승인한다.

## 이번 산출물의 한계

C의 점검 순서/사용자 표시 경계를 준비했다. 실행 코드·rate limit·알림·복구 자동화는 추가하지 않았다.
실제 비밀 회전·장애 주입·백업 복원·배포/롤백은 수행하지 않았다. A/B/Soo 확인과 선행 구현 뒤
실측 증거를 채워야 #400 완료를 판단할 수 있다.


## B 의견 반영 — 원자적 판정과 관측

두 제어를 함께 켜는 정책인지 독립 제어인지 A/B/C가 합의해야 한다. UI에는 실제 적용된 효과만 표시한다.
접수 차단만 적용하고 '유료 처리 전체 중단'이라고 안내하지 않는다. 설정 이름·초기값은 여기서 확정하지 않는다.
차단과 전송 허가가 경합할 때 원자적 판정 시점, 이미 허가된 in-flight 시도의 취급은 #396 gate 계약에 따른다.
관측 구간은 차단 요청 시각이 아니라 서버가 확정한 판정/허가 이벤트로 구분한다.

| 관측 | 증거 | 제외할 민감 label |
|---|---|---|
| 신규 접수 | job/예약 생성 건수 및 거부 건수 | 질문·원문·계정 자격 |
| 실제 전송 | provider attempt ID별 단계·전송/거부 수 | 토큰·주장·본문 |
| 정산 | reserved/observed/unknown/not_sent 변화, 중복 정산 여부 | 제공자 응답 원문 |
| 처리 시간 | 단계별 소요·임베딩 준비·결과 저장/재생 성공 | 사용자 질문·파일 경로 |

공유 메트릭 label에는 owner/execution ID 같은 고유 식별자도 넣지 않는다. 필요한 상관관계는 접근 통제된
원장/진단에서 확인하고 티켓에는 합성 별칭·건수만 기록한다. 임계값·SLO·금액은 실측/Soo 결정 전 미확정이다.
위 추가 절차는 미실행이며 실제 중단 제어나 원장을 구현한 것이 아니다.

## C 내부 운영 상태 표시

`interfaces/mcp/remote_operation_preview.py`는 `PostgresRemoteOperationControls.get()`의
두 제어를 읽어 같은 안내를 HTML/텍스트로 만든다. `intake_enabled`의 현 구현 대상인
**신규 PDF 처리 접수**로 표현하며 모든 질문 실행까지 차단한다고 확대하지 않는다.
접수만 중단/추가 전송만 중단/둘 다 중단/둘 다 허용을 구분한다. 허용 표시는 동의·예산·권한
재검사를 대체하지 않는다. 이미 전송된 요청·usage unknown을 환급으로 표현하지 않는다.

전체 MCP 중단 여부는 서버 설정으로 별도 전달한다. 중단 시 MCP 조회도 영향을 받으며 웹 가용성은
별도 확인 대상으로 안내한다. 상태 미확인/DB 오류/잘못된 값은 고정 안내로 표시하고 자동 재시도하지 않는다.
설정 변경·공개 도구·제품 카드 연결은 없으며 미리보기는 외부 입력을 제어 승인으로 쓰지 않는다.
단위 회귀와 `test_remote_operation_preview_postgres.py`의 실제 DB 조회 조합을 구분한다.
