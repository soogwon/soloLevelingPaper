# 원격 메모의 논문 상세 연결

## 문제와 변경

원격 도구에서 저장한 기록은 `/remote-learning/{context}` 전용 화면에서 조회됐지만,
일반 논문 상세의 로컬 동기화 목록에는 나타나지 않았다.
상세 화면에 원격 메모·하이라이트 영역을 추가한다. 현재 로그인 owner의 현재 논문·선택 판본에서
명시적으로 시작한 학습 맥락만 조회하고, 맥락 선택 후 기록과 인용문을 표시한다.

- GET `/v1/remote-annotation-products/contexts?paper_id=...&version_id=...`
- 웹 세션 전용, 서버 인증 owner 사용, 삭제 논문 제외
- 맥락 UUID 커서, 기본 20/최대 50개; 시작하지 않은 context를 생성하지 않음
- 선택 맥락의 기존 annotation GET으로 기록 더 보기, ID 중복 제거
- 동의·수정·삭제는 같은 맥락의 기존 관리 화면으로 이동
- 로그아웃·세션 만료·화면 이동 이후 늦은 응답 폐기
- 조회 실패를 정상 빈 목록으로 표시하지 않으며, 현재 판본과 다른 응답을 거부
- 기존 문자열 판본 식별자 계약 유지; migration·DB 추가 권한 없음

## 검증

로컬 격리 PostgreSQL에서 owner/판본 격리, 맥락 커서 순회, 논문 삭제 후 제외 및 제한 역할 조회를 검증한다.
웹 대역에서는 GET 전용, XSS 이스케이프, 다른 판본/맥락 거부, 더 보기/새로고침,
로그아웃·세션 만료 뒤 응답 폐기를 확인한다. 이 변경은 staging에 아직 배포하지 않았다.

별도로 이전 배포 `5ffd136`에서 사용자가 두 번째 계정의 GET/PATCH/DELETE를 실행해
모두 404/annotation_not_found를 관측했고 첫 계정의 하이라이트 2건/revision 1 보존을 확인했다.
이 결과는 사용자 직접 확인이며 새 상세 화면 배포 검증으로 간주하지 않는다.

## 남은 범위

새 상세 화면 실제 배포와 다기기 확인, Claude 제품 카드 생성·복구 수신 확정,
실제 응답 유실/동시 생성, 원문·번역 revision 변경 시나리오는 별도 검증이 필요하다.
현재 원격 맥락 목록은 UUID 오름차순이며 첫 맥락 선택을 최신 학습 추천으로 해석하지 않는다.
전체 기록 페이지 순회는 스냅샷이 아니므로 동시 추가/삭제 후에는 다시 조회한다.
