# 원격 MCP 연결 가이드 (스테이징)

## 범위

이 문서는 Solo Leveling Paper의 원격 MCP를 Claude에 연결하는 사용자 절차를 설명한다. 원격 MCP는 OAuth로 사용자를 인증하고 서버에서 논문 처리와 기록 저장을 수행한다. Python, 로컬 검색 모델과 사용자의 OpenAI API 키는 필요하지 않다.

현재 공개 주소는 **스테이징·시험용**이다. 기능 플래그, 배포나 점검 상태에 따라 연결할 수 없을 수 있으며 프로덕션 가용성이나 데이터 영구 보존을 보장하지 않는다.

로컬 데이터와 모델을 PC에서 직접 관리하려면 [Claude Desktop 로컬 MCP 설치·배포](desktop-installation.md)를 사용한다.

## 준비물

- 사용자 지정 커넥터를 추가할 수 있는 Claude 계정
- 브라우저
- Solo Leveling 웹 계정
- 등록할 PDF(최대 크기와 허용 형식은 업로드 화면의 현재 안내를 따른다)

Claude 계정과 Solo Leveling 계정은 별개다. 웹과 MCP 커넥터에는 **같은 Solo Leveling 계정**으로 로그인해야 같은 논문과 기록이 보인다.

## 1. 웹 계정 준비

1. [Solo Leveling 스테이징 웹](https://solo-leveling-staging.soogyung.com)을 연다.
2. 로그인하거나 새 계정을 만든다.
3. 로그인 후 계정 화면에 표시되는 이메일을 확인한다.

## 2. Claude에 원격 MCP 추가

1. Claude에서 **설정 → 커넥터(Connectors)**를 연다.
2. **사용자 지정 커넥터 추가(Add custom connector)**를 선택한다.
3. 이름과 주소를 입력한다.

   ```text
   이름: Solo Leveling
   주소: https://solo-leveling-staging.soogyung.com/mcp
   ```

4. 추가한 커넥터에서 **연결(Connect)**을 누른다.
5. 브라우저 로그인 화면에서 1단계와 같은 Solo Leveling 계정으로 로그인한다.
6. 표시된 권한 범위를 읽고 승인한다.

Claude 버전과 요금제에 따라 메뉴 이름이나 위치가 조금 다를 수 있다. 이 주소는 원격 HTTP MCP이므로 `claude_desktop_config.json`의 stdio 서버 목록에는 넣지 않는다.

## 3. 연결 확인

1. Claude에서 새 대화를 연다.
2. 도구 또는 커넥터 목록에서 **Solo Leveling**이 활성화됐는지 확인한다.
3. 다음과 같이 요청한다.

   ```text
   Solo Leveling 연결 상태를 확인해줘.
   ```

인증 성공 여부와 현재 환경이 반환되면 연결된 것이다. 현재 스테이징 응답에는 `authenticated: true`와 `staging-spike` 같은 환경 이름이 표시될 수 있다. 환경 이름은 배포 설정에 따라 달라질 수 있다.

## 4. PDF 등록과 처리

원격 MCP는 채팅에 첨부한 PDF를 자동으로 받지 않는다. PDF는 웹을 통해 등록한다.

1. 웹의 **새 PDF 등록** 화면을 연다.
2. PDF를 고르고 파일 정보를 전송하는 단계의 안내를 확인한다.
3. PDF 보관 범위에 동의하고 업로드한다.
4. 업로드 검증이 끝나면 AI 전송 범위와 비용 주체 안내를 확인한다.
5. AI 전송에 동의하면 서버가 처리를 시작한다.
6. 웹에서 처리 상태가 완료됐는지 확인한다.
7. Claude에서 “내 논문 목록을 보여줘”라고 요청한다.

파일 보관 동의와 AI 전송 동의는 서로 다른 단계다. 취소하거나 동의하지 않은 단계의 데이터는 전송하지 않는 것이 제품 계약이다. 실제 화면의 문구와 상태가 이 설명과 다르면 작업을 반복하지 말고 오류와 작업 ID를 기록한다.

## 5. 사용 예시

```text
내 논문 목록을 보여줘.
Attention 논문의 선수 개념을 알려줘.
이 논문의 학습 경로를 만들어줘. 목적은 전체 구조 이해야.
왜 sqrt(d_k)로 나누는지 논문 근거와 함께 설명해줘.
이 근거에 메모를 남겨줘.
```

도구별 원격 지원 범위는 계속 확장 중이다. Claude가 도구를 찾지 못하면 임의의 일반 답변인지 Solo Leveling MCP 결과인지 구분해서 확인한다.

## 연결 해제와 재연결

다음 경우에는 Claude의 커넥터 설정에서 Solo Leveling을 연결 해제한 뒤 다시 연결한다.

- 승인 범위가 변경된 뒤 기존 연결에 새 권한이 반영되지 않을 때
- 다른 Solo Leveling 계정으로 연결해야 할 때
- 인증 세션이 만료됐는데 자동 갱신되지 않을 때

재연결만으로 서버의 논문과 학습 기록이 삭제되지는 않는다. 서버 데이터 삭제는 별도의 삭제 동의와 제품 흐름을 따른다.

## 문제 해결

### 커넥터를 추가할 수 없음

- Claude 계정에서 사용자 지정 커넥터가 지원되는지 확인한다.
- 주소 끝의 `/mcp`를 포함했는지 확인한다.
- 스테이징 서비스가 배포 또는 점검 중인지 확인한다.

### 로그인 후 인증되지 않음

- 팝업 차단을 해제하고 로그인 절차를 다시 완료한다.
- 웹과 커넥터가 같은 Solo Leveling 계정인지 확인한다.
- 커넥터를 연결 해제한 뒤 다시 연결한다.

### 웹에는 논문이 있지만 Claude 목록에 없음

- 두 화면에 표시된 계정 이메일이 같은지 확인한다.
- PDF 업로드뿐 아니라 필요한 AI 전송 동의와 서버 처리가 완료됐는지 확인한다.
- 웹에서 논문 처리 상태와 오류 코드를 확인한다.

### Claude에는 연결됐지만 도구가 보이지 않음

- 새 대화를 만들고 Solo Leveling 커넥터를 활성화한다.
- 해당 기능이 아직 원격 MCP에 노출되지 않았을 수 있으므로 [GitHub Issues](https://github.com/soogwon/soloLevelingPaper/issues)를 확인한다.

## 데이터와 비용

- 원격 PDF와 학습 기록은 연결된 계정의 서버 저장소에 보관된다.
- 원격 처리의 외부 AI 호출은 서비스 인프라와 서비스 정책을 사용하므로 사용자 OpenAI API 키는 필요하지 않다.
- PDF 원문과 일부 내용이 저장 또는 외부 처리될 수 있다. 각 동의 카드에서 전송 항목과 범위를 확인한다.
- 시험 운영 중에는 보존 기간, 사용량 제한과 지원 범위가 바뀔 수 있다.

원격 MCP의 인증·소유권 설계는 [원격 MCP 전환 설계](../architecture/25-remote-mcp-transition.md), 실제 검증 범위는 [원격 MCP 스테이징 검증](remote-mcp-staging-validation.md)을 참고한다.
