# 원격 학습·메모 최소 권한 준비

`grant_annotation_role(conn, schema, role)`는 승인된 관리자 연결로 명시 호출한다.
서버 시작 시 실행하지 않으며 역할·비밀번호를 생성하거나 staging을 변경하지 않는다.
새 전용 비특권 역할에 적용하는 추가 권한 함수이며 기존 역할의 과도한 권한을 회수하는 함수가 아니다.

- SELECT: 논문, 고정 context/publication, 원문·번역 청크, 원격 학습 기록, 메모, 생성 요청 원장.
- INSERT: 원격 학습 기록·메모·생성 요청 원장만.
- UPDATE: 학습 상태/revision, 메모 본문·단계·삭제용 구간 초기화/revision, 요청 state/수신 확인만.
- 논문/context/publication의 식별자 UPDATE는 행 잠금 요건만 충족하며 역할별 trigger가 실제 UPDATE를 거부한다.
- DELETE, 세션·기기 자격 조회, 원문·예산·요청 입력 지문·소유권 변경은 허용하지 않는다.

이 역할은 여러 사용자의 요청을 처리하는 서버 역할이다. 사용자별 격리는 인증 owner와
저장소 쿼리가 책임지며 DB 역할 자체가 사용자별 RLS 경계인 것은 아니다.
기존 질문용 공용 잠금 거부 함수(0041)를 재사용하고 역할별 trigger 이름을 분리한다.

로컬 실제 비특권 연결에서 시작/완료/이어하기, 생성 재전송/복구/확정/삭제 및 금지 SQL을 검증한다.
후속 CRUD의 expected_revision·목록·동의 검사는 이 권한 검증과 별개다.
공개 MCP scope·동의·제품 카드와 실제 환경 적용은 미연결이다.

staging 적용 시에는 전용 역할 생성·자격 보관·권한 부여·서비스 설정·복구안을 먼저 승인받는다.
복구는 신규 연결 비활성화 후 해당 역할 권한과 역할별 잠금 trigger를 회수한다.
기존 서비스 역할이나 학습 데이터를 삭제하지 않는다.
