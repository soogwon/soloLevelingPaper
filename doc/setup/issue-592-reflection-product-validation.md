# #592 성찰 동의 API·원격 도구 연결

성찰 전용 storage 동의는 인증 웹 세션에서 고지·질문 판본을 확인한 뒤
기록한다. MCP는 동의를 조회하지만 생성하지 않는다. 동일 맥락의 동시 동의
저장은 한 활성 동의만 유지하며 철회는 새 쓰기를 차단한다.

원격 질문·비교·동의 조회는 `reflections:read`, 작성/삭제는
`reflections:write`가 필요하다. 기존 메모 권한으로 대체하지 않으며
읽기 사용자에게 새 전역 필수 권한으로 요구하지 않는다.
도구는 모델 입력에서 owner를 받지 않고 검증 identity의 owner를 사용한다.

A: 동의/저장의 부모 잠금 순서와 revision을 유지한다.
B: 비교는 고정 질문과 저장 답변만 사용한다. 유료 호출·의미 평가가 없다.
C: 웹 동의 라우트와 MCP 도구를 주입 가능하게 연결했다. 사용자 화면,
환경 설정·전용 역할·Auth0 및 실제 Desktop/다기기 검증은 남는다.

격리 PostgreSQL·도구 14개, 웹 세션 경계 테스트를 수행했다.
실제 staging 변경·외부 API 호출은 없다. 기본 서비스 조립은 하지 않는다.
