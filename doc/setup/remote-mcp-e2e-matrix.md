# #397 원격 MCP 종단 검증표 — C 준비본

상태: 모든 행 미실행. 선행 #388~#396, #399, #400의 구현/운영 준비 후 승인된 스테이징에서 실행한다.
계약·대역 테스트의 성공을 이 표의 실환경 통과로 옮겨 적지 않는다.
운영 데이터/유료 제공자 호출은 별도 승인 없이 사용하지 않는다.

최신 main의 부분 근거는 [저장·검색·삭제 검증 대조표](issue-397-main-evidence.md)에 별도로 기록한다.
DB/단위 테스트 결과로 아래 종단 행의 상태를 통과로 바꾸지 않는다.

## 준비 및 증거 규칙

- 서로 다른 두 테스트 계정 A/B와 공개 재배포 가능한 PDF를 사용한다. 이름은 합성 별칭만 기록한다.
- A/B의 paper/version/context/job/evidence는 실제 서버가 발급한 서로 다른 ID로 준비한다.
- 재파싱 전 P1과 재파싱 후 P2, P1의 원문/번역/메모/근거 스냅샷을 제한된 테스트 저장소에 보존한다.
- 요청 키는 제출 전에 보관한다. 토큰·presigned URL·본문을 스크린샷/일반 로그/티켓에 남기지 않는다.
- 유료 전송이 필요한 행은 미실행으로 두거나 승인된 대역으로 실행하고 결과에 '대역'을 명시한다.
- UI만 보고 중복 없음/비용 0을 판단하지 않는다. A/B가 제공하는 job/예약/attempt/게시 건수와 대조한다.
- 오류 비교는 외부 응답 status/reason/schema로 한다. 타 사용자 ID와 무작위 미존재 ID를 비교한다.

## 담당 연결과 완료 판정

A: 인증/소유권·원장·삭제·복원 증거, B: 검색/답변/출처/호출 수 증거,
C: 호스트별 재연결·동의/상태·카드/텍스트 표시 증거를 대조한다.
선행 기능이 없으면 '해당 없음'으로 통과시키지 말고 '보류: 선행 티켓'을 적는다.
실패는 재현 입력의 합성 ID·기대/실제 상태·고정 오류만 공유하고 원본 자격/본문은 제외한다.
모든 필수 행의 실환경 범위·제외 사유·검토 기록을 합의한 뒤 #397 종료를 판단한다.
본 문서 작성만으로 #397 또는 #77을 종료하지 않는다.


## B 증거 대조 — 세부 인수 기준

기존 E2E-03/07/09/10/11/12의 성공 표시는 아래 증거와 함께 판정한다.
범위 밖 ID가 결과에 없다는 사실, model_checked 표시, 화면의 '완료'만으로 통과시키지 않는다.
고정 합성 fixture의 정답/허용 구절은 실행 전에 사람이 검토해 잠그며 결과에 맞춰 바꾸지 않는다.

| ID | 준비·실행 | 대조할 증거/통과 조건 | 실제 결과·증거 |
|---|---|---|---|
| EVD-01 | 다른 owner/revision/페이지/섹션의 더 높은 점수 후보와 허용 집합의 필수 근거를 삽입 | 사전 필터 top_k 안에 필수 근거 유지. 전역 top_k 후 필터 oracle과 비교 | |
| EVD-02 | 기본 [6], [6]+strict_pages=true, [6,7]을 같은 질문으로 실행 | 검색→보충→생성 선택지→의미 검증→저장/반환에서 조건별 허용 구절 ID/범위 일치 | |
| EVD-03 | 페이지 끝 문장 뒤에 새 문장과 번역 정렬 없는 구간 준비 | 허용된 문장 완성만 포함, 다음 새 문장 유입 없음, 정렬 없는 quote_ko를 검증된 인용으로 반환하지 않음 | |
| EVD-04 | 사람이 정한 필수 답변/근거에 실제 저장 답변을 대조 | model_checked를 정답으로 가정하지 않음. 수치/핵심 주장/인용 충족을 각각 확인 | |
| EVD-05 | partial/insufficient, 예산 부족, 제공자 장애, 검증 미완료를 각각 주입 | 답변 품질과 실행 제한이 혼동되지 않음. 미검증 주장을 검증 완료로 승격하지 않음 | |
| EVD-06 | P1 context 저장 후 P2 게시, P1 재조회 | parse/translation/embedding set/publication·저장 quote/근거 ID가 전후 동일 | |
| EVD-07 | 응답 유실·재연결·usage unknown 뒤 동일 실행을 조회 | 추가 생성/임베딩/보완/의미 검증/provider attempt 0회, 저장 답변 품질/status 유지 | |
| EVD-08 | 삭제/접근 차단 후 P1 조회와 늦은 worker 재시도 | 정상 재처리의 보존과 구분하여 접근 정책 적용. 최신본/로컬 사본 fallback 없음 | |

페이지 6/7은 경계 fixture의 번호다. 실제 PDF에 적용할 때는 해당 판본의 검증된 페이지/문장으로
매핑하고 판본을 기록한다. 실제 논문 본문/질문을 외부 API에 보내는 검증은 승인 범위 안에서만 수행한다.
partial publication의 색인 누락과 답변의 partial은 별도 관측값으로 남긴다.

### 같은 실행의 증거 연결

| 계층/담당 | 제공할 증거 | 공유 방법 |
|---|---|---|
| A DB/worker/원장 | owner 범위·고정 publication·job/attempt/예약·게시/정산 건수 | 합성 실행 별칭, 단계별 전후 건수 |
| B 검색/검증 | 허용 후보/구절/출처·검증 수준·실제 전송 카운터 | 고정 fixture ID와 판정, 원본 본문 제외 |
| C 호스트 | 제출 전 키 보관·재연결·동의/상태·카드/텍스트 | 같은 실행 별칭의 순서/시각·안전한 화면 |

카운터는 재조회 직전/직후를 비교한다. 비용 추정액만으로 추가 호출 0을 판단하지 않는다.
ID/본문 원본은 제한된 테스트 저장소에서 대조하고 일반 로그/PR에는 넣지 않는다.
이 세부 표는 미실행이며 실제 DB·검색·호스트의 종단 증거를 대신하지 않는다.
