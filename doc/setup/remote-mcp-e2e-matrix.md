# #397 원격 MCP 종단 검증표 — C 준비본

상태: 모든 행 미실행. 선행 #388~#396, #399, #400의 구현/운영 준비 후 승인된 스테이징에서 실행한다.
계약·대역 테스트의 성공을 이 표의 실환경 통과로 옮겨 적지 않는다.
운영 데이터/유료 제공자 호출은 별도 승인 없이 사용하지 않는다.

## 준비 및 증거 규칙

- 서로 다른 두 테스트 계정 A/B와 공개 재배포 가능한 PDF를 사용한다. 이름은 합성 별칭만 기록한다.
- A/B의 paper/version/context/job/evidence는 실제 서버가 발급한 서로 다른 ID로 준비한다.
- 재파싱 전 P1과 재파싱 후 P2, P1의 원문/번역/메모/근거 스냅샷을 제한된 테스트 저장소에 보존한다.
- 요청 키는 제출 전에 보관한다. 토큰·presigned URL·본문을 스크린샷/일반 로그/티켓에 남기지 않는다.
- 유료 전송이 필요한 행은 미실행으로 두거나 승인된 대역으로 실행하고 결과에 '대역'을 명시한다.
- UI만 보고 중복 없음/비용 0을 판단하지 않는다. A/B가 제공하는 job/예약/attempt/게시 건수와 대조한다.
- 오류 비교는 외부 응답 status/reason/schema로 한다. 타 사용자 ID와 무작위 미존재 ID를 비교한다.

## 담당 연결과 완료 판정

A: 인증/소유권·원장·삭제·복원 증거, B: 검색/답변/출처/호출 수 증거,
C: 호스트별 재연결·동의/상태·카드/텍스트 표시 증거를 대조한다.
선행 기능이 없으면 '해당 없음'으로 통과시키지 말고 '보류: 선행 티켓'을 적는다.
실패는 재현 입력의 합성 ID·기대/실제 상태·고정 오류만 공유하고 원본 자격/본문은 제외한다.
모든 필수 행의 실환경 범위·제외 사유·검토 기록을 합의한 뒤 #397 종료를 판단한다.
본 문서 작성만으로 #397 또는 #77을 종료하지 않는다.
