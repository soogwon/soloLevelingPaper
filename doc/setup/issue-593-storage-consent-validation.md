# #593 퀴즈 답안 저장 동의 검증

웹 `#/quizzes/{contextId}/{quizId}/consent`에서 고정 퀴즈별 답안·점수·오답 근거 저장 동의를 명시적으로 기록·철회한다. AI 생성·전송 동의는 포함하지 않는다. 동의 조회에 정답은 포함하지 않는다.

- A: 부모 잠금 아래 동시 동의를 하나로 합치고, 소유자·context·퀴즈 snapshot hash로 저장 범위를 고정했다. 철회 후 새 제출은 막고 기존 같은 키 결과는 재조회한다.
- B: 잘못된 고지·판본의 동의는 거부한다. 새 퀴즈에는 기존 동의가 적용되지 않는다. 채점 방식은 기존 고정 퀴즈의 로컬 규칙을 유지한다.
- C: 웹 세션 전용 API, 임의 confirmed 필드 거부, 명시 체크, 응답 유실 후 조회 복구, 로그아웃 후 늦은 응답 차단을 검증했다.

로컬 PostgreSQL 5개, HTTP 대역 2개, 웹 전체 190개 통과. 실제 환경 변경·AI 호출 없음.

운영 서비스 조립·DB 권한·Auth0·제품 진입 링크와 실제 브라우저/Desktop 검증은 남아 있다. 퀴즈 생성 worker·생성 예산/AI 동의·제출/복습 카드는 이 변경에 포함하지 않는다. 기존 기록 삭제·내보내기 연결도 후속이다.
