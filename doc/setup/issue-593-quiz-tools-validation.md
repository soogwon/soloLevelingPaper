# #593 원격 퀴즈 조회·제출 도구 대역 검증

저장소를 명시 주입하면 원격 퀴즈 조회·제출·시도 상세·이력·단계 점수·오답
조회 도구를 등록한다. `quizzes:read/write`는 기존 읽기 사용자에게 전역 필수
권한으로 추가하지 않는다. 인증 owner만 사용하고 모델이 owner를 지정하지 않는다.

AI 생성·검수 퀴즈 저장·동의 기록 도구는 노출하지 않는다. 새 제출은 저장소의
별도 동의와 퀴즈 판본 검사를 거친다. 원문 근거는 추측하지 않고 시도에 고정된
근거 ID까지만 제공한다. 실제 근거 본문 조회는 후속 연결이다.

도구 대역 7개와 요약/기존 MCP 경계 포함 23개 검증 후 실제 MCP의 bool 답안
보존을 추가 확인했다. `true`를 선택지 1로 변환하지 않고 저장소 검증에 넘긴다.
기존 로컬 성찰·퀴즈 236개 회귀도 통과했다. Ruff·diff 통과.

실제 API·staging 변경 없음. 동의 사용자 화면·기능 설정·전용 권한·생성 실행·
실제 호스트·다기기 검증은 남는다. 서비스는 자동 활성화하지 않는다.
