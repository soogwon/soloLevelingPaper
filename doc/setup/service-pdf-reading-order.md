# 서비스 PDF 읽기 순서 보완

2026-11-18. 스킬 PR #601과 별도로 서비스 extract_pages 경로에서 합성 2단 PDF의
좌우 문장과 절 제목이 한 줄로 합쳐지는 문제를 재현했다.

- 중앙 18pt 영역에 글자가 없고 좌우에 각각 최소 5줄이 확인된 페이지를 분리한다.
- 본문보다 앞선 폭 전체 제목은 보존하고 왼쪽 단 다음 오른쪽 단으로 읽는다.
- 본문과 제목 글꼴 분석에 같은 영역 순서를 적용한다. 제목 offset은 최종 페이지 본문 기준이다.
- 기존 기준으로 확인된 하단 쪽 번호는 단 판별 전에 분리한다. 인용용 printed_page_label은 채우지 않는다.
- 회전 문자 제외 및 제외량 집계, 페이지 경계, 청킹 인터페이스를 유지한다.
- 분할 전후 문자·좌표·개수를 대조해 경계에서 글자가 잘리거나 중복되면 기존 추출로 돌아간다.

혼합 배치·중간의 폭 전체 캡션·좁거나 비대칭인 여백·짧은 페이지는 보수적으로 기존 추출을 유지한다.
따라서 모든 다단·표·수식의 읽기 순서를 해결한 것은 아니다. OCR이나 표 복원도 추가하지 않는다.

실제 합성 PDF에서 1단 공백 오인 방지, 2단 제목·본문 순서, 쪽 번호, 회전 문자, 페이지 경계,
메모리 PDF를 사용하는 원격 ProcessingPdfParser의 절별 청크·동일 입력 재실행을 검사한다.
유료 API·R2·DB·실제 논문 종단 실행은 하지 않는다.

기존 저장 청크·번역·색인·근거는 수정하지 않는다. 기존 논문에 새 추출을 적용하려면 기존 결과를
덮어쓰지 않고 서비스의 재파싱/새 리비전 절차로 진행해야 한다. 이전 파서가 쓴 리비전에
새 텍스트를 덮어쓰는 운영은 이번 변경에 포함하지 않는다.
