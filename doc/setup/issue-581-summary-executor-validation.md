# #581 명시적 요약 단일 실행 대역 검증

원격 요약 실행 ID를 명시적으로 선택하는 runner와 영속 전송 gate 조립체를
추가한다. 자동 queue 등록·기능 flag·staging 설정은 추가하지 않는다.

- A: 동일 실행을 동시에 처리해도 하나만 claim한다. 기한·삭제·철회·기존 시도
  여부를 확인하고 기존 전송 이력이 있으면 자동 재전송하지 않는다. 공통
  heartbeat/lease·실패 종료·미사용 예산 반환을 사용한다.
- B: 고정 원문·번역과 근거 ID로만 요약하며 원문 속 지시를 따르지 않도록
  지시한다. 근거가 부족하면 빈 결과를 허용하지만 완료 저장은 하지 않는다.
  provider/model/prompt/language/정책을 고정 입력과 대조하고 토큰 상한을
  영속 원장에서 검사한다. 자동 보완·의미 검증 호출은 추가하지 않는다.
- C: 저장 결과는 같은 요청 키로 조회하며 읽기에는 새 생성이 없다.

실제 PostgreSQL + 대역 HTTP 회귀에서 동시 실행 단일 전송, 재시작 재조회,
빈 결과·잘못된 근거·응답 유실 후 재전송 차단, 철회 후 HTTP 미호출을 검증했다.
실제 외부 API는 호출하지 않았다.

## 남은 범위

준비/동의 웹 화면·review 만료·MCP 도구와 카드, 자동 대기열/종료 처리,
최신 성공 요약 선택·근거 재조회·내보내기, 전용 역할·scope·운영 이미지 연결이
남는다. 현재 runner는 명시적으로 선택한 한 건만 처리하는 내부 코드다.
실제 배포/권한 변경과 유료 호출은 별도 승인 후 진행한다.
