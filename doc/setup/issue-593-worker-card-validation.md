# 원격 퀴즈 생성 worker와 제출·복습 카드 검증

Refs #593. 실제 staging 변경·PDF 전송·AI 호출 없이 합성 대역과 로컬 격리 PostgreSQL로 검증한다.

## 구현 경계

- A: `RemoteQuizRunner.run(owner, execution_id)`가 접수된 퀴즈 1건만 claim한다. 기존 질문 heartbeat·실행 세대·만료·취소·예산 원장을 사용한다. provider attempt가 있는 중단 작업은 자동 재전송하지 않는다.
- B: `PersistedQuizExecutor`는 고정 모델/프롬프트/정책/토큰 상한을 대조하고 기존 영속 전송 gate로 최대 1회 호출한다. 구조 검사와 **명시적으로 주입한 로컬 의미 검증기**가 모두 통과해야 저장한다. 기본 의미 검증기나 추가 AI 검증 호출은 제공하지 않는다. 대역 검증 통과는 실제 정답 품질의 증거가 아니다.
- A·B: 현재 lease·동의·미삭제 논문·같은 고정 판본 및 observed 사용량을 다시 확인한다. 실행별 결정적 quiz ID로 문항 저장과 실행 완료를 같은 트랜잭션에 반영한다. 완료 실패 시 문항도 롤백한다.
- C: 생성 요청 키로 정답을 숨긴 완료 퀴즈를 조회한다. `show_remote_quiz`에서 명시적으로 답안을 제출하고, 응답 유실 시 `get_remote_quiz_submission`으로 같은 키만 조회한다. `show_remote_quiz_review`는 저장 시도의 점수·오답·정답·고정 근거 ID를 표시한다. 본문 근거 조회는 기존 근거 도구를 사용한다.
- 답안 저장 동의는 기존 인증 웹 흐름에서 받는다. 카드가 동의를 대신 기록하지 않는다. 토큰 변경 시 이전 카드의 제출·복구를 거부하며 새 입력·취소·pagehide 뒤 늦은 응답을 표시하지 않는다.

## 자동 검증

- PostgreSQL·MCP·HTTP·기존 동의 및 요약 회귀 결합: 123 passed.
- 퀴즈 UI: 12 passed(원격 신규 9개 포함).
- 로컬 퀴즈 저장·제출·이력 및 MCP 회귀: 150 passed(앞 묶음과 중복 포함, 합산하지 않음).
- 실제 서버 Docker 이미지의 네트워크 차단 조립 검사 통과. 기존 퀴즈 MCP 모듈 누락을 보완하고 로컬 저장소 import를 로컬 메서드로 제한했다.
- 실제 FastMCP 카드 resource/앱 전용 제출 도구 metadata 확인.
- 생성 동시 실행 1회, 완료 재조회/재시작, 다른 owner 거부, 철회·취소·만료 전송 0회, 불명 사용량 자동 재전송 차단, 늦은 완료·lease 만료·의미 검증 실패 저장 차단, 문항/완료 원자 롤백.
- 카드 응답 유실 후 조회만 수행, 연결 변경·새 입력·취소·화면 이탈 후 결과 차단, HTML 이스케이프, 동의 미충족 제출 차단.

## 남은 범위

운영 큐 선택/CLI·최소 DB 역할·설정 조립, 신뢰 가능한 입력 토큰 상한과 실제 의미 검증기 조립, staging/실제 Desktop 및 다기기·두 계정 검증이 남는다. 이 변경은 서버 시작 시 worker를 자동 실행하거나 feature flag를 켜지 않는다. 실제 모델 생성의 품질·과금 실측은 별도 승인 후 수행한다. #593을 자동 종료하지 않는다.
