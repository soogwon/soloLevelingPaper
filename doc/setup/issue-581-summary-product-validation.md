# #581 요청형 요약 제품 연결 대역 검증

기존 검토 서비스 주입 시 원격 MCP 준비·검토 조회·접수·결과 조회·취소와
웹 `#/summaries/{request_key}` 화면을 연결한다. 기능 환경 설정은 아직
추가하지 않아 운영에서 자동 활성화하지 않는다.

- A: 인증된 owner와 요약 전용 권한만 허용한다. 취소는 이 검토의 실행만
  대상으로 하며 재조회에 생성이나 접수를 섞지 않는다.
- B: 웹에서 고정 범위·판본·근거 수·모델·호출/토큰 상한과 비용 발생을
  고지한다. 상한을 확인할 수 없으면 동의·접수를 차단한다.
- C: 저장·전송 동의를 각각 받는다. 조회만으로 동의하지 않으며 모델의
  `confirmed` 입력도 없다. 로그아웃 후 늦은 응답을 버리고 응답 유실은
  같은 키의 GET으로 복구한다. 기존 요약은 새 생성 없이 표시한다.

웹 대역 6개, MCP·HTTP 경계 32개, 요약 검토·도구·라우트 15개를 확인했다
(범위 간 중복 포함). 실제 외부 API 호출과 staging 변경은 없다.

## 남은 범위

전용 설정·역할·Auth0 권한·배포, worker 큐/운영 조립, 논문 상세의 최신 성공
요약과 내보내기/근거 조회 연결, 실제 Claude·다기기·유료 품질 검증이 남는다.
웹 검증은 Node 대역이며 실제 브라우저 또는 Desktop 검증이 아니다.
`summaries:write`는 지원 권한으로만 고지하고 기존 읽기 사용자에게 새
전역 필수 권한으로 요구하지 않는다. 기능 활성화는 별도 승인 후 진행한다.
