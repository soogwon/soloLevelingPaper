# #592 성찰 저장 동의 화면 검증

`#/reflections/{contextId}/consent`는 현재 웹 계정의 학습 맥락별 저장 동의를 조회한다. 최초 진입은 GET만 수행하며 사용자가 체크하고 저장을 누를 때 고지 버전·질문 revision을 보낸다. AI 동의나 호출은 포함하지 않는다.

- A: 서버의 기존 소유권·웹 세션·CSRF·revision 검사를 사용한다. 응답 유실은 GET으로 복구한다.
- B: 현재 고지·맥락과 불일치한 응답은 동의 입력에 사용하지 않는다. 철회와 기존 답변 삭제를 구분한다.
- C: 명시 체크 전 저장 차단, HTML 이스케이프, 철회, 응답 유실, 로그아웃 뒤 늦은 응답 차단을 Node 대역 5개로 확인했다. 요약 화면 회귀 6개도 통과했다.

실제 브라우저·Claude Desktop·다기기 검증은 하지 않았다. 운영 역할·Auth0 권한·서비스 조립·staging 배포가 남아 있다. 답변 작성/비교 화면과 제품 내 진입 링크는 후속이다. 실제 환경 변경과 API 호출은 없다.
