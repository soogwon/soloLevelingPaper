# #593 퀴즈 생성 입력·결과 계약

원격 퀴즈를 실제 생성하기 전 필요한 고정 입력을 준비한다. 서버가 조회한 완전 게시의 학습 맥락·판본·선택 근거 1~20개, 학습 단계, 문항 수/유형, 제공자·모델·프롬프트·언어·예산 정책과 토큰 상한을 canonical hash에 포함한다. 원문·번역 근거는 기존 SummarySource 데이터 형식을 재사용한다. 서버 소유권 검증을 대체하지 않는다.

생성 저장·AI 전송 동의를 별도 목적으로 검사한다. 답안 제출 저장 동의, 다른 계정/맥락/판본, 철회·만료 동의는 재사용하지 않는다. 물리 호출 상한은 1회이며 이 계약은 호출하거나 예산을 예약하지 않는다.

결과는 요청한 수·유형의 모든 문항이 통과해야 반환한다. 알 수 없는/중복 근거, 중복 문항, 잘못된 선택지/정답 위치, 정답 문구 모순, 잘린 부분 결과를 거부한다. 의미적 근거 일치·교육 품질을 검증한 것으로 간주하지 않는다. 반환 문항을 검수 완료 저장소에 자동 기록하는 연결은 없다.

A·B·C 대역 48개와 로컬 PostgreSQL 준비 1개: 고정 입력 해시·목적 분리·동의 만료·구조 검증·고지 원문 비노출. Ruff 통과. 실제 API·staging 변경 없음.

저장된 완료 답변의 실제 인용만 고정 출처로 재조회하는 서버 준비 어댑터도 추가했다. 잘못된 계정·없는 근거·삭제 논문은 준비하지 않는다. 전체 논문 근거를 자동 선택하거나 아직 저장되지 않은 근거를 등록하지 않는다.

다음 범위: 새 근거 준비/출처 저장, 생성 동의 웹, DB 접수·예산·lease·취소/복구·실행 runner, 의미 검증, 생성 결과 저장·카드. 실제 호출에는 전송 내용·모델·횟수·비용 상한 승인이 필요하다.
