# 원격 학습 맥락별 저장 동의와 제품 연결

사용자 결정: 학습 맥락별 1회 동의 후 메모·하이라이트 작성·수정을 허용하며 철회할 수 있다. PDF 보관 동의와 외부 AI 전송 동의는 대체하지 않는다.

## A: 저장과 권한

0044는 owner/context별 동의 이력을 저장한다. 동일 활성 고지의 동의 재전송은 같은 consent_id를 반환한다. 철회 후 재동의는 새 revision이다. 과거 동의 ID로 현재 동의를 철회할 수 없다. 학습 맥락이 바뀌면 동의도 다시 필요하다.

저장과 철회는 논문 부모 행 잠금으로 직렬화한다. 철회 후 신규 작성·수정은 거부하되, 기존 키 재생·조회·복구·삭제는 유지한다. 동의 전 거부된 요청 키는 저장하지 않는다.

MCP 역할에는 동의 조회만 허용한다. 별도 인증 웹 역할에만 INSERT 및 revoked_at UPDATE를 허용한다. 공용 서비스 역할은 사용자별 RLS가 아니므로 인증 owner 조건과 HTTP/MCP 경계 검증이 필수다.

## B: 도구 계약

검증된 원격 identity와 papers:read 및 annotations:read/write를 사용한다. owner·service ID는 사용자 입력으로 받지 않는다. 학습 시작은 명시적 요청만 처리하며 메모 쓰기는 학습 기록과 유효한 저장 동의를 모두 요구한다. 동의 부여 MCP 도구는 제공하지 않는다.

응답 유실 시 같은 키 조회 또는 초기 입력 전체 복구를 사용한다. 모호함·삭제·충돌을 새 키 생성으로 회피하지 않는다. 근거 구간은 생성 시 검증하고 수정에서는 바꾸지 않는다.

## C: 웹 연결

`/#/remote-learning/{context_id}`에서 고지 확인·체크 후 동의, 철회, 목록·더 보기, 본문 수정·삭제를 제공한다. 조회만으로 학습 시작이나 동의를 만들지 않는다. 로그아웃·인증 만료·화면 이탈 후 늦은 응답은 버린다. 저장 응답 유실 시 자동 재전송하지 않고 재조회를 안내한다.

새 메모·하이라이트 작성은 MCP 도구를 사용한다. 웹 세션·CSRF 인증 경계 아래에서만 동의를 부여한다.

## 검증과 남은 범위

로컬 격리 PostgreSQL에서 동의 전 차단, 재전송, 철회 후 새 작성·수정 차단 및 기존 조회·삭제, 재동의 이력, 타 계정과 다른 맥락 격리, 제한 역할 권한을 검사한다. HTTP·MCP 인증과 웹 응답 유실·로그아웃 경계는 대역 테스트로 검증한다.

이번 변경은 명시적 서비스 주입만 지원하며 기존 배포에서 자동 활성화하지 않는다. 전용 웹/MCP DB 설정 조립, Auth0 scope 등록, 실제 Desktop 카드·기기 간 복구, staging migration/권한 적용은 후속이다. 실제 staging 변경·논문 전송·AI 호출은 하지 않았다. #580/#502는 아직 종료하지 않는다.
