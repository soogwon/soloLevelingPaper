# 원격 annotation 저장 CRUD (#580)

기존 원자 생성·키 복구 포트에 단건/목록 조회와 조건부 수정·삭제를 추가한다.

- 새 제품 생성은 `require_learning=True`로 호출하며 학습 기록이 없으면 입력 키를 남기지 않는다.
  기존 내부/로컬 테스트 호출의 기본 동작은 유지한다. 이미 커밋된 키의 복구도 유지한다.
- 조회·변경은 owner/context/annotation ID가 모두 일치해야 한다. 삭제 논문이나 다른 범위는 None이다.
- 수정은 본문과 단계만 바꾼다. 원문/번역 구간·출처·작성 주체는 불변이다.
- 수정/삭제는 현재 revision을 요구한다. 동일 revision의 동시 변경은 하나만 성공한다.
- 삭제는 본문/구간을 지우고 키 이력을 deleted로 보존한다. 같은 생성 키 재사용은 거절한다.
- 목록은 불변 annotation UUID 오름차순 keyset이며 20건 기본, 최대 50건이다.
  조회 중 새 삽입의 snapshot을 보장하지 않는다. 새로고침은 첫 페이지에서 시작한다.
- 삭제 응답 유실은 기존 키 조회의 deleted 상태로 확인한다. 새 키로 재생성하지 않는다.

검증: 실제 PostgreSQL에서 학습 미시작 키 미잔류, 수정 뒤 구간 유지, 오래된 삭제 거절,
타 계정 차단, 삭제 재생성 차단, 동시 수정, 51건 페이지 중복/누락 없음 확인.
전용 비특권 계정으로 단건/목록·수정/삭제·수신 확인도 검증한다.

staging 변경·AI 호출은 없다.
