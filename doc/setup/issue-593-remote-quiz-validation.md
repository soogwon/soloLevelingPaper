# #593 검수 퀴즈 저장·제출 기반

이번 범위는 내부 검수 퀴즈의 불변 저장과 제출 기반이다. AI 생성이나
사용자 입력으로 퀴즈를 만드는 엔드포인트가 아니다. 생성 동의·예산·worker는
별도 구현 전까지 연결하지 않는다. `store_reviewed`는 MCP/웹에 노출하지 않는다.

- A: owner/context/판본과 근거를 대조하고 quiz ID의 내용을 덮어쓰지 않는다.
  동일 제출 키는 단일 시도이며 다른 답안 재사용은 충돌이다. 새 키는 재응시다.
- B: 기존 로컬 객관식·단답형 채점기를 재사용한다. 단답형은 정규화한 정답
  문구와의 정확 일치만 인정하며 AI 평가나 의미 일치를 보장하지 않는다.
- C: 제출 전 조회에는 문항·선택지만 보이고 정답·채점 기준·근거 ID는 숨긴다.
  제출 후 시도에는 정답·내 답·근거 ID가 포함되어 오답 복습의 기반이 된다.
  시도 목록은 페이지당 1~100건이며 단계별 최신/최고 점수를 제공한다.

새 제출에는 퀴즈 ID·내용에 고정된 `remote-quiz-attempt-v1` 저장 동의가
필요하다. 철회 후 새 시도는 차단하지만 기존 결과와 같은 키 재생은 유지한다.
조회·제출·채점은 API를 호출하지 않는다.

격리 DB 4개 및 migration·백업/복구 포함 32개 통과 후 최신/최고 점수
회귀를 다시 확인했다. Ruff·diff 통과. 실제 staging 변경·외부 API 호출 없음.

## 남은 범위

생성 입력·동의·예산 예약·실행 lease·생성 사용량 검증과 worker, MCP/웹·동의
카드·오답 근거 실제 조회, 계정 내보내기/삭제 제품 연결, 실제 두 계정·다기기
종단 검증이 남는다. 현재 기반만으로 원격 퀴즈 생성 완료를 주장하지 않는다.
migration 0055 및 전용 권한·운영 배포는 별도 승인 후 적용한다.
