# #63 퀴즈 카드 검증

2026-11-03에 Windows Claude Desktop에서 별도 wheel과 합성 SQLite DB로 확인했다.
테스트용 `context_id=ctx`, `step=preview`에서 `get_quiz`를 호출해 객관식 한 문항과 단답형 두 문항을 열었다.

| 문항 | 카드의 채점 결과 | 오답 근거 | DB에 저장된 근거 ID |
| --- | --- | --- | --- |
| 객관식 | 정답 | — | `e1` |
| 단답 하나 | 오답 | PDF 2페이지 `Second.` | `e2` |
| 단답 둘 | 오답 | PDF 1페이지 `First.`, 2페이지 `Second.` | `e1`, `e2` |

승인 후 카드를 확인했을 때 제출과 오답 근거 조회가 이미 끝난 상태였다.
표시된 결과를 DB와 대조했다. 두 곳 모두 점수는 1/3이었고, DB에는 시도 1건, 문항 답안 3건, 요청 키 1건이 있었다.

## 재검증 방법

1. 합성 퀴즈가 있는 환경에 카드가 포함된 wheel을 설치하고 Desktop에서 MCP 서버를 다시 연결한다.
2. `get_quiz`로 카드를 열어 객관식은 정답, 단답형은 오답으로 제출한다.
3. 카드에 1/3과 문항별 채점 결과가 표시되는지 확인한다. **오답 원문 근거 보기**를 눌러 위 표의 페이지와 인용문을 대조한다.
4. 저장 상태는 합성 DB에서 읽기 전용으로 확인한다. 기존 시도가 있다면 이번 제출 전후의 증가분을 비교한다.

응답 유실 후 같은 요청 키로 재확인하는 동작과 이전 퀴즈의 늦은 응답 처리는 `ui/quiz`에서 `npm ci`와 `npm test`로 검증한다.
