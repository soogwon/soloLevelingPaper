# LinkMix: 합성 시퀀스 처리 비교 보고서

> 평가 자료 작성을 위해 만든 가상 논문이다. 방법·데이터·수치는 실제 연구 결과가 아니다. 페이지는 가상 PDF의 물리 페이지이며 실제 PDF 파일을 파싱한 결과가 아니다.

## 가상 PDF 물리 페이지 1

### 출처 b01 · 섹션 s1

1. 방법과 비교 기준
Gate는 연결 점수로 입력 벡터를 가중합한 표현을 만드는 가상 방법이다. Chain은 입력 위치를 순서대로 갱신하는 가상 비교 방법이다.

### 출처 b02 · 섹션 s1

n은 입력 시퀀스의 길이이고 d는 표현 차원이며, 둘 다 양의 정수이다. 이 합성 보고서는 층당 이론적 연산량을 C_Gate=n²d, C_Chain=nd²로 정의한다. 그 점근적 표기는 각각 O(n²d), O(nd²)이다. 비교 조건은 정의한 연산량 식을 기준으로 하며, 이는 실제 실행 시간을 측정한 값이 아니다.

### 출처 b03 · 섹션 s1

Gate의 최소 순차 연산 수는 O(1)이고 Chain은 O(n)이다. 최소 순차 연산 수는 층당 총 연산량과 다른 비교 기준이다. 순차 연산 수만으로 실제 실행 시간의 우열을 확정할 수 없다.

### 출처 b04 · 섹션 s2

2. 합성 측정 기록
Synth-A 분류 실험에서 n=32, d=128일 때 Gate의 정확도는 92%, Chain의 정확도는 88%였다. 두 수치는 같은 평가 집합에서 측정했다.

### 출처 b05 · 섹션 s2

실행 시간 기록 A: n=64, d=128, 장치 X, 배치 1이라는 설정에서 Gate는 8ms, Chain은 12ms였다.

### 출처 b06 · 섹션 s2

실행 시간 기록 B: n=64, d=128, 장치 X, 배치 1이라는 같은 설정에서 Gate는 15ms, Chain은 11ms였다. 이 보고서는 기록 A와 B의 우열이 달라진 원인을 설명하지 않는다.
